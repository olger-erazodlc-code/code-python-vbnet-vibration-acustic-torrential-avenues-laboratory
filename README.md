# code-python-vbnet-vibration-acustic-torrential-avenues-laboratory
The repository contains Python code for training SVMs and Random F. using acoustic and microseismic features obtained from experiments involving rock displacement under different flow rates. It includes a CSV file with 78 columns, audio and video files, and experimental data, as well as a module for extracting, merging, and classifying the signals.

This repository contains the Python code developed to train Support Vector Machine (SVM) and Random Forest models, using features extracted from acoustic and microseismic signals. The data were obtained from experiments conducted in a channel with variable and fixed slopes, in which rock displacements and impacts were simulated under different flow conditions.

It also includes a CSV file consisting of 78 columns. The first column corresponds to the experiment code, the second to the record number, and the third to the class: 0 (low flow), 1 (medium and high flow), and 2 (very high flow). The next 45 columns contain spectral characteristics of the acoustic signals, while the remaining 30 correspond to temporal and spectral characteristics of the microseismic signals generated by the movement of solids and the impact of rocks against the channel bed.

The repository also contains three folders with audio, video, and CSV data files corresponding to the experiments conducted, which can be used to validate the classification process using the software module. Additionally, the installers for the developed module are included. To verify the classification process, follow the numbered steps indicated on the interface buttons: first, select the path where the files are located; next, select a CSV file containing vibration data and an audio file whose name includes the tag audio_video. The system then extracts the features from the microseismic and acoustic signals, integrates both representations, and finally runs the classification model.
